## 1. 产品定义

| 项 | 内容 |
|---|---|
| 产品 | 安卓为主的**个人学习助手**，双角色：**秘书**（提醒任务 / 日程 / 倒计时）+ **教练**（发现薄弱点后用 AI 陪跑「学 → 会 → 记住」） |
| 不是 | 不是「待办清单 + 网课浏览器」的拼装，而是**以规划为主干、会话为执行单元、费曼复述为理解检验核心**的双闭环系统 |
| 用户 | **深圳中学高中生**，广东**新高考 I 卷**（3+1+2，数学不分文理）、**人教 A 版 2019** |
| 主用设备 | **vivo S7**（6.44" / 2400×1080 / 20:9 / 408ppi / 60Hz / Android 10，Compact 360dp，碎片端）＋ **联想拯救者 Y900 13"（TB522FU）**（约 3840×2560 / 144Hz / Android 16，Expanded 横屏，整块端 / 分屏主战场）；家人 iQOO / 红米 / iPhone，**安卓为主** |
| 环境硬约束 | **教学区域禁用电子设备**；**课间用不了手机**；**进考场前可以用手机** |
| 首个真实场景 | 上完数学课发现「基本不等式」薄弱 → 建 15 天规划，目标「能解决 75% 相关题目、遇到同类题脑中有思路」 |

## 2. 需求基线（完整回顾后的归纳）

### 2.1 从使用情境到框架（元要求）

> 用户明确要求：**不要从表面情境看，要深层次把使用情境归纳于软件框架**。本文与全部设计据此写法：不复述情节，而是抽象实体、闭环与层次。

| 起点情境 | 归纳 |
|---|---|
| 早晨推送「背单词」 | 不是特指，是**习惯性任务**的实例；「一键打开」= 任务带跳转外部 App 的执行动作；实现形态改为**桌面 Widget 最小态** |
| 看「距下一个任务多久」 | **倒计时 + 开始前提醒**（振动 / 声音 / 无） |
| 「立即开始 / 将来开始」 | 告知**存在两个选项**，是 `Plan.startMode` 字段，不是流程分支 |
| 「先跳过摸底测验」 | **不是一定要，但是有的** = 可跳过节点（Optional Stage） |
| 「复习模式 2」 | **不是二选一，就是模式 2**，固定不可配 |
| 「Notein 内置」 | 严格内嵌不可行（无 SDK / 系统不允许）→ **A/C/D 三通道并存** |
| 「固定格式导入导出」 | 格式由本项目设计，本质 = **全量数据可携带 / 可迁移** |

### 2.2 一贯的设计偏好（跨轮次反复出现）

| 偏好 | 证据 | 落地为约束 |
|---|---|---|
| **信息克制** | Widget 只显示最近任务 + 倒计时；考前卡一行一个坑；拒绝笔记合订「太冗长」；桌面组件「小一点」 | 默认最小态，细节按需展开；不合订、不堆功能 |
| **可选但存在** | 提醒方式、开始时机、摸底测验、笔记显隐、提前量 2/5、挑战/刷自信 | 统一归 **L0 策略与开关层**，不各自造开关 |
| **要真实、可校验，不要黑箱** | 「AI 自己生成会和考试内容风格相差很大」；归因选 ①②③ 排除 ④ 自由归因；要求「细化到考试时直接看那个知识点」 | **高考对齐约束层** + 预设维度归因 + 一份坐标体系 |
| **数据主权** | 本地存储、所有数据能带走、别的设备能用 | `.studypack` 全开放格式；凭证不进包 |

### 2.3 七轮拍板结论（已收敛，不得再改）

| # | 结论 |
|---|---|
| 1 | 学情基线 `ExamProfile`：新高考 I 卷 + 人教 A 版 2019；知识点树挂靠教材目录，首个锚点 `必修一·2.2 基本不等式` |
| 2 | 绿色 = 多来源、会变、按天确认的 **`SlotPool` 时段池**（法一/法二/法三/自定义四源）；法二**不做爬虫**；课间与教学区域过滤 |
| 3 | **桌面 Widget** 常驻、只显示最近任务 + 倒计时；提前量 **2 分钟**，也可 5 / 自定义，建规划时设 |
| 4 | 错因归因 **①知识结构 + ②高考能力 + ③费曼暴露 三维结合**，产出 `WeakPoint` 条目与考前速查卡，细化到知识点叶子节点 |
| 5 | 变式 **②按薄弱程度自适应 + ④变形强度四档**；新增 `SessionIntent`（跟随 / 挑战 / 刷自信）与**防污染标记** |
| 6 | AI 笔记与手写笔记 **④ 分开存、双向关联**，靠 `anchorId` 本地索引快速对应，**默认不交给 AI** |
| 7 | `.studypack` **① 纯开放不加密**（代价：拿到文件即可读全部学习轨迹，用户已确认接受） |

### 2.4 达标语义（最易写错的一条）

> **75% 是双层**：单次测验正确率 ≥75% = **会话通过线**（进总结环节）；15 天到期整体解决率 ≥75% 且「脑中有思路」= **规划目标线**（规划收口）。
> 未达标 **不是重学、不是直接换题**，而是 `AI 错因归因 → 继续费曼 → 再测一遍`，循环至通过线。

## 3. 建设蓝图总览

| 层 | 内容 | 对应功能 |
|---|---|---|
| **L0 策略与开关层**（横切） | 提醒方式 / 提前量 / 开始时机 / 摸底测验 / 笔记显隐 / 数据外发白名单 / SessionIntent；复习模式固定不可配 | F4 |
| **闭环① 任务/习惯维系** | Widget 最小态 → 今日视图 → 全局日历；任务、倒计时、提醒、跳转 | F5 F6 |
| **闭环② 能力精进** | 发现薄弱 → 建规划 → 会话学习 → 费曼总结 → 复习闭环 → 达成目标；未达标归因回路 | F7 F8 F9 F10 |
| **L1 能力层（可插拔）** | AI 服务层 / 资源适配器层 / 笔记子系统 / 高考对齐约束层 / 全局时间视图 | F11 F12 F13 |
| **L2 数据底座** | 本地存储 + 主动/手动保存 + `.studypack` 全量迁移 | F1 F2 F3 |

> **一份坐标体系**（知识点树节点 ID）贯穿 **资源标签 → 错因归因 → 笔记关联 → 复习调度**；四个环节共用同一套 ID，不各造一套。

**两个闭环共用**同一套 AI 能力层、笔记/资源接入层、全局时间视图与本地数据底座。

## 4. 功能规格（开发 WBS · 每个功能都必须带测试）

> 编号 `F1–F14` 即开发顺序与测试编号。每个功能的「验收标准」是可写成断言的条款；**测试不通过不得进入下一个功能**。

### F1 · 领域模型与学情基线
- **实现**：全部实体（Task / Plan / Session / Review / SlotPool / SlotTemplate / SchoolCalendar / WidgetView / WeakPoint / ExamReminderCard / NoteDocument / AnchorLink / Resource / ExamProfile / DataPackage）的可序列化模型；`ExamProfile` 预置深中基线（卷别、3+1+2、数学不分文理、人教 A 版、题型 8+4+4+6 / 150 分、难度 5:3:2、2026 命题风格）。
- **规则**：知识点树挂靠教材目录；首个锚点 `人教A版·必修第一册·第二章·2.2 基本不等式`；每实体 `toJson/fromJson` 往返无损。
- **验收**：① 全实体 JSON 往返字段零丢失；② 知识点树可定位到叶子节点；③ 题型分值合计 = 150；④ 难度 5:3:2 归一化为 1.0；⑤ 未知枚举值反序列化必须报错而非静默降级。
- **测试**：`tF1_models.dart`

### F2 · `.studypack` 全量导入导出（地基）
- **实现**：`manifest.json`（`schemaVersion` / 导出时间 / 设备 / checksum）+ 14 类实体 JSON + `assets/{pdf,ink,images}`；导出为纯开放格式，不加密。
- **规则**：`api_key` 等凭证**不进包**；第三方版权内容**不进包**（只存引用与考纲标签）；`checksum` 覆盖全部实体文件；`schemaVersion` 递增时旧版本必须可导入或明确报错；导出设备写入 manifest，但**导入不做设备假设**。
- **验收**：① 导出→导入后全部实体逐字段一致；② 篡改任一文件后校验失败；③ 含 `api_key` 字段的输入被拒绝进包；④ 缺 `manifest.json` 的包被拒绝；⑤ 空包 / 单实体包可用；⑥ 跨「设备」导入结果一致。
- **测试**：`tF2_studypack.dart`

### F3 · 本地存储与保存
- **实现**：本地仓储（可注入的存储后端），**主动（自动快照）+ 手动保存**两种触发；保存后可从仓储完整恢复。
- **规则**：数据全在本地；保存失败不得静默吞错；快照与手动保存写同一份真源。
- **验收**：① 写入→重启（新建仓储实例）→恢复一致；② 自动快照按阈值触发；③ 手动保存立即生效；④ 存储异常向上抛出。
- **测试**：`tF3_storage.dart`

### F4 · L0 策略与开关层
- **实现**：全局默认 + 单次会话覆盖；策略点：提醒方式（振动/声音/无）、提前量（默认 + 预设 2/5 + 自定义）、开始时机（立即/将来）、摸底测验显隐、内置笔记区显隐（全局默认 + 单次可改）、数据外发白名单、SessionIntent；**复习模式固定模式 2，不可写、不可配**。
- **规则**：显隐开关**只影响渲染，不删除数据**；`SessionIntent` 仅当次生效，不写回全局；所有策略随 `.studypack` 导出。
- **验收**：① 每个策略点默认值正确；② 会话级覆盖不污染全局；③ 关闭笔记区后归档内容仍可被检索；④ 尝试修改复习模式必须被拒绝；⑤ 配置往返无损。
- **测试**：`tF4_preferences.dart`

### F5 · 任务与提醒（闭环①）
- **实现**：习惯性 / 一次性任务；周期调度；今日日程；「距下一个任务」倒计时；`reminderMode` + `leadMinutes` 提醒；`action` 一键跳转外部 App；规划排定的学习时段写回日程，同样受倒计时与提醒管辖。
- **规则**：提前量三层（全局默认 / 2·5 预设 / 自定义，建规划时覆盖）；**设备禁用时段（教学区域 / 考场内）自动静默，不响不亮屏**；倒计时按分钟级更新。
- **验收**：① 习惯任务按周期生成下一次；② 倒计时对跨日、跨零、同刻边界正确；③ 提醒时刻 = 任务时刻 − 提前量；④ 「无」与禁用时段不产生提醒；⑤ 跳转动作可序列化且不含凭证；⑥ 规划时段出现在今日日程里。
- **测试**：`tF5_tasks.dart`

### F6 · `SlotPool` 时段池（四来源 + 容量匹配）
- **实现**：四来源 Slot（课程表手动标绿 / 校源日程 / 常驻模板 / 临时自定义）；`SlotTemplate` 预置 4 段 `07:00–07:30 / 13:00–13:30 / 17:20–18:20 / 21:30–21:50`，可开关、当天可取消；`SchoolCalendar` 含课程 + 考试 + 活动，自动供给校运会类临时空档。
- **规则**：**绿色 = `空闲 ∧ 设备可用 ∧ 能用手机 ∧ 时长够`**；课间与教学区域时段自动过滤；四段合计 **140 分钟/天**；**按时段容量匹配学习环节**——碎片（20/30min）放复习闭环，整块 60min 才排新内容；会话可**拆分、跨时段续接**；时段消失时排期可重排；截图导入为批量一次性，非实时同步。
- **验收**：① 四来源合并去重、按天确认；② 课间/禁用时段被过滤；③ 140 分钟容量计算正确；④ 20min 时段只被分配复习环节、60min 才能分配新内容；⑤ 取消某时段后排期重排且无孤儿；⑥ 重叠时段检测；⑦ 校历活动自动生成可用时段。
- **测试**：`tF6_slotpool.dart`

### F7 · 规划创建（闭环②起点）
- **实现**：目标 + 量化指标（75%）+ 时间界限（15 天）+ `startMode`（立即/将来）+ 从日历挑绿色时段引用 + 提前量设置；状态机（进行中 / 达成 / 到期）。
- **规则**：`slots` 引用 SlotPool 而非复制；立即开始即创建首个 Session；到期按**规划目标线**判定（整体 ≥75%）；目标必须可量化。
- **验收**：① 必填校验（目标 / 指标 / 时限 / 时段）；② `startMode` 两值都可创建；③ 时段引用指向池中现存 Slot；④ 立即开始生成首个会话、将来开始不生成；⑤ 15 天到期收口且按目标线判定；⑥ 指标 75% 与会话通过线 75% **是两个独立字段**。
- **测试**：`tF7_plans.dart`

### F8 · 学习执行引擎（会话状态机 · 核心）
- **实现**：`资源就绪 →〔摸底测验：可选可跳过〕→ 视频学习 + 笔记 → 相关测验 → 判定`；达标 → `总结（我复述 → AI 纠正 → 反复 → 确认理解）→ 生成个性化 AI 笔记 → 生成复习计划纳入规划`；未达标 → `AI 错因归因 → 回到费曼复述-纠正 → 再测一遍`，循环至通过线。
- **规则**：**双层 75% 严格分离**；摸底测验可跳过、内置笔记区可开关（关闭不渲染但不删数据）；**复习闭环固定模式 2**：`复述上次理解 → AI 纠正 → 反复确认 → 几道简单练手题 → 今日新内容`，**不可配、不可跳过**；复习时默认只显示 AI 笔记 + 考前速查卡，我的笔迹按需展开；归因写回 Plan，调后续资源难度与复习权重。
- **验收**：① 全路径可达（含跳过摸底、关闭笔记）；② 达标与未达标分支互斥；③ 未达标回路确实经历「归因→费曼→再测」且循环至通过；④ 复习计划确实写入 Plan；⑤ 复习模式不可跳过、不可配置；⑥ 总结环节必须经历「确认理解」才生成 AI 笔记；⑦ 会话按容量匹配环节（接 F6）。
- **测试**：`tF8_session.dart`

### F9 · 三维归因 `WeakPoint` 与考前速查卡
- **实现**：错因打三轴（①知识结构 / ②高考能力 / ③费曼暴露，含「假懂」）；产出可定位到知识点**叶子节点**的条目：节点、三维标签、薄弱程度、证据（题号 + 复述原句）、一行考前提醒；`ExamReminderCard` **同源双渲染**（屏幕态 / 打印态黑白可读，内容一字不差）。
- **规则**：**排除 ④ AI 自由归因**（禁止「基础不牢」类无证据结论）；每条必须有证据；标签复用高考对齐词典；薄弱程度量化（频次 / 跨时段重复 / 假懂加权），驱动复习权重与练手难度；打印态**不能只靠颜色**区分（描边 + 图标 + 文字冗余编码）。
- **验收**：① 三轴齐全、可为空但不可缺轴；② 无证据的条目被拒绝；③ 假懂加权使程度升高；④ 跨时段重复使程度升高；⑤ 屏幕态与打印态文本完全一致；⑥ 打印态含非颜色标记；⑦ 程度等级驱动复习权重单调变化。
- **测试**：`tF9_weakpoint.dart`

### F10 · 变式题、难度与临场意图
- **实现**：主路径 **②按薄弱程度自适应 + ④变形强度四档递进**（换数字 → 换情境 → 换设问 → 开放探究）；`SessionIntent`（跟随系统 / 挑战 / 刷自信），进练习前点选；题库需备到压轴档；难度按高考 **5:3:2**。
- **规则**：**防污染**——做题记录带 `来源模式 = 自适应 / 意图覆盖`，归因与薄弱程度评级**只认自适应**；「刷自信」做对中档题不得降低薄弱程度；「挑战」直上开放探究档；变式题必须挂靠真实母题 `parentId`。
- **验收**：① 四档递进可枚举且顺序固定；② 薄弱程度升高 → 优先基础/中档巩固；③ 意图覆盖记录带来源标记；④ **意图覆盖的作答不参与评级**；⑤ 无 `parentId` 的变式题被拒绝；⑥ 难度分布符合 5:3:2 容差。
- **测试**：`tF10_variants.dart`

### F11 · 笔记子系统（A/C/D 三通道 + 双向关联）
- **实现**：A 系统分屏/跳转（外部引用 + 可选快照）、C PDF 桥接归档、D 内置笔记区（可显隐）；**AI 笔记与「我的笔记」两份独立存储**；`anchorId = 知识点节点ID + SessionID + WeakPointID`；`AnchorLink` 本地索引表支持双向跳转（AI 笔记段落 ↔ 我的笔迹）。
- **规则**：**默认不把笔记交给 AI**；建立/查看对应纯本地索引、离线可用；AI 读取笔迹需**主动触发**且只送该锚点下一小段（最小必要外发 + 脱敏）；A 通道原件始终是外部引用，只有 C 通道归档回来的那份可被处理；OCR/视觉识别结果**只作可检索摘要，绝不覆盖原始笔迹**；手写识别错不污染数据。
- **验收**：① 两份笔记独立存、不合订；② `anchorId` 双向查询都能命中且毫秒级（纯本地）；③ 关闭 D 通道不删除 A/C 归档；④ OCR 摘要与原件分离；⑤ 隐藏笔记区后归档仍可检索（接 F4）；⑥ 主动触发才调用 AI，未触发零外发。
- **测试**：`tF11_notes.dart`

### F12 · 资源适配器与高考对齐约束
- **实现**：四种统一接入模式（分屏/跳转 A · 文件桥接 C · 引用登记 + 跳转 · 本地导入）；`Resource` 强制带 `source`、教材版本/考纲标签、年份地区、题型·分值·难度、`parentId`、变形档位。
- **规则**：资料优先级 `自己的资料 > 权威题库 > B站视频(仅跳转) > AI 生成(受限)`；**AI 从「生成者」降级为「检索匹配 + 讲解 + 基于真实母题的变式」**；**禁止无来源题冒充高考题**；B站只存元数据（标题/BV号/时长）；学科网内容不进包；`.studypack` 只带走引用与标签。
- **验收**：① 缺 `source` 的资源被拒绝；② 无来源题不得标记为「高考题」；③ 变式题必有 `parentId`；④ B站资源不含视频二进制；⑤ 四通道接入不改变主流程；⑥ 考纲标签可映射到 `ExamProfile` 知识点树。
- **测试**：`tF12_resources.dart`

### F13 · AI 服务层（可插拔）
- **实现**：**能力接口固定**（分析薄弱点 / 检索资源 / 出题 / 判卷 / 错因归因 / 复述纠正 / 生成笔记 / 生成复习计划 / 截图→结构化识别）+ **Provider 适配器可换**（`DeepSeekAdapter`：`base_url` / `api_key` / `model_id` / 思考模式；另提供 `MockAdapter` 供离线测试）。
- **规则**：`api_key` 存系统密钥库、**不进 `.studypack`**；**最小必要上下文**（只送当次所需，可配白名单）；**优雅降级**——无 key / 无网时 AI 节点标「待处理」，**不阻塞看视频、记笔记、做已有题目**；换模型只改配置；默认 `deepseek-flash`（「4.1 Pro」非正式在售型号，禁止写入配置）。
- **验收**：① 能力接口调用不依赖具体模型；② 换 Provider 主流程零改动；③ 导出包不含任何凭证字段；④ 无 key / 无网时返回「待处理」且非 AI 功能可用；⑤ 外发上下文受白名单约束；⑥ 截图识别产出结构化数据而非 PDF 文本。
- **测试**：`tF13_ai.dart`

### F14 · 界面第一版（可运行、可验收）
- **实现**：按 §5 视觉规范实现页面：桌面 Widget 最小态契约 / 今日视图 / 全局日历 / 任务详情与编辑 / 规划创建 / 学习会话 / 复习闭环 / 薄弱点速查卡 / 笔记 / 我的（L0）/ 数据导入导出；**双端断点**（Compact 底部 4 Tab 单栏 / Medium NavigationRail / Expanded Rail + 双栏）；消费同一份 `.studypack` schema。
- **规则**：绿色只表示**可学习时段**（方案 A）；打印态黑白可读；信息克制（默认最小态）；手机与 Pad 两端都要有样式；分屏导致窗口宽度回落 Medium 时自动重组。

### 5.4 硬约束（界面层，不得违反）

1. **信息克制**：Widget 只一个任务 + 倒计时；考前卡一行一个坑；笔记不合订。
2. **绿色 = 可学习时段专色**，不挪作成功/完成（按方案 A）。
3. **三层视图**：Widget 最小态 → 今日 → 全局日历（三层叠加）。
4. **教学区域禁用电子设备** → 必须有打印/导出纸质入口；打印态**黑白仍可读**，不能只靠颜色。
5. **进考场前可用手机** → 速查卡屏幕态 / 打印态**同源双渲染，内容一致**。
6. **设备矩阵**：手机与 Pad 两端都要出样式；不写死分屏布局，需降级形态。
7. **流程状态可见**：5 阶段 + 未达标归因回路 + 固定复习模式。
8. **一切「可选但存在」**：界面要表达「有这个功能，但用不用由我定」，不把流程写死。
9. **离线可用**：无网/无 key 时 AI 节点标「待处理」，看视频、记笔记、做已有题目不卡住。

## 6. 数据契约 `.studypack`

### 6.1 目录结构

```
studypack-YYYYMMDD-HHMM/
├── manifest.json          # schemaVersion / 导出时间 / 设备 / checksum
├── preferences.json       # L0 全部策略
├── exam_profile.json      # 学情基线 + 知识点树 + 题型 / 难度
├── school_calendar.json   # 课程 + 考试 + 活动 + 禁用规则
├── slot_pool.json         # 时段池 + 常驻模板 + 当天确认状态
├── tasks.json             # 习惯性 + 一次性任务（含提前量与跳转动作）
├── plans.json             # 目标 / 量化指标 / 时限 / startMode / slots 引用
├── sessions.json          # 状态机 / 测验记录 / SessionIntent / 来源模式标记
├── weak_points.json       # 薄弱点条目 + 证据 + 一行考前提醒
├── review.json            # 复习计划与状态（固定模式 2）
├── ai_notes.json          # AI 笔记（独立一份）
├── my_notes.json          # 我的笔记（独立一份，含 A/C/D 来源通道）
├── anchor_links.json      # anchorId ↔ 两份笔记的块/页
├── resources.json         # 资源引用：只存元数据与出处
└── assets/{pdf,ink,images}/
```

### 6.2 规则

1. **纯开放不加密**：JSON(UTF-8) + SVG + PDF + Markdown，别的设备/程序直接读，导入无需口令。
2. **凭证不进包**：`api_key` 排除；换设备重新填。
3. **第三方版权内容不进包**：B站视频、学科网题库只存引用 + 考纲标签；自导入资料属本地资产，随包带走。
4. **自描述 + 校验**：`manifest.json` 带 `schemaVersion` 与 `checksum`；版本递增需兼容性测试。
5. **速查卡双渲染同源导出**，屏幕态与打印态内容一致。
6. **带走的不是一堆文件**，是带考纲标签、可追溯、带关联锚点的结构化资料 —— 换设备后「贴切高考」与「两份笔记对得上」都不丢。

## 8. 工程方案与第一版范围

### 8.1 环境事实（2026-11-14 实测）

| 能力 | 状态 |
|---|---|
| `dart`（Dart SDK 2.17.0） | ✅ 可直接运行、可编译 |
| `dart2js` / `dart compile js` | ✅ 可编译 JS |
| `flutter` 主命令 | ⚠️ 沙箱内 `flutter_tools.snapshot` 启动挂起（缺包解析 + 联网阻塞），**无法执行 `flutter build` / `flutter test`** |
| 无头 Chromium | ✅ 可做渲染、DOM 与截图校验 |
| Git → GitHub | ✅ 已固化 HTTP/1.1 + 短超时重试 |

### 8.2 由此确定的分层（重要工程决策）

> **业务逻辑只有一份真源**：纯 Dart 领域内核（`lib/`），零第三方依赖、兼容 Dart 2.17、只用 `dart:core / convert / math`，因此**既能被 Dart 测试运行器覆盖，也能被编译/复用**。

## 9. 质量门禁（用户明确要求，不得放宽）

1. **每写一个功能，立即写该功能测试并运行**；**测试全部通过才进入下一个功能**。
2. **测试不得降低要求**：不得删断言、不得放宽断言、不得跳过失败用例、不得以「冒烟通过」代替完整用例。每个功能的验收标准（§4）**逐条**转成断言。
3. **失败即修**：任一断言失败 → 修实现或修测试规格（若确实是规格错，必须同步改 §4 与 §11）→ 重跑到全绿。
4. **所有功能完成后再做一次全部功能测验（全量回归）**：`run_all.dart` 跑完 F1–F14 全部用例，输出 PASS/FAIL 统计；**全绿之后才找用户**。
5. **界面另做浏览器实测**：Chromium 无头渲染，检查无溢出 / 错位 / 中文方块，并校验与 `.studypack` 的读写闭环。
6. 每次测试结果留痕（提交信息与 `docs/测试报告.md`），可追溯哪个功能在何时、以多少用例通过。
