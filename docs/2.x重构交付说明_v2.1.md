### 千问设计稿评审结论（用户本轮追加）

- **可沿用**：低饱和暖白 + 墨蓝 `#204066` / 琥珀 `#E0892E` / 松绿 `#2E7D5B`（仅表示可学习空闲时段）/ 朱砂 `#C0492F` 的语义、4 步抽屉、平板「列表＋详情」分栏、弹层置顶。
- **已补齐的缺口**：① 时段选择改为日历式并加「自定义添加空闲时段」（原稿只有固定时段列表 + 25/50/90 分按钮）；② 向导补「薄弱点」步骤；③ 补「学情基线」（地区 / 学校 / 卷别 / 教材版本 / 考试模式）与首启引导；④ 平板按验收标准保留顶部导航（原稿为左侧竖 Dock，若后续改需求可切换）。
- **不能当成品**：静态设计稿无持久化、无真实校验、无页面跳转。

## 2. 实现要点

- `web/index.html` 单文件交付界面，`android/app/src/main/assets/index.html` 与之**逐字节一致**（tF15 断言）。
- 持久化：`openDB / idbGet / idbPut / idbDel`；`scheduleSave()` 微任务合并写盘；`autoSaveGuard()` 在每次交互后比对状态指纹，任何增删改立即落盘；业务函数保留显式 `save()` 双保险；写失败明确 `feedback(...,'err')`，不静默吞错。
- 凭证：`deviceKey()` 用 IDB 内 32 字节随机种子派生 AES-GCM 密钥；`seal/unseal`；`Storage.prototype` 透明封装，落盘为密文、读取为明文；`S` 与 `.studypack` 永不含 Key。
- 布局：`#device` 即 `100dvh` 全屏根容器；CSS 媒体查询按窗口宽度重排；`data-force` 仅用于冻结断言与「我的 → 界面布局」手动选择。
- 原生质感：`contextmenu` / `selectstart` 全局拦截（输入框、`.note-area`、`.selectable` 例外）。

## 6. 如实说明的边界

- AI 真实回复内容仍依赖用户在本机填写的真实 Key；已验证请求格式 / 鉴权头 / 端点可达 / 失败绝不伪造。
- WebDAV 为**预留的手动同步接口**：浏览器 `file://` 页面受跨域策略限制时，上传/下载会如实失败；APK 内若需稳定跨端同步，可后续通过原生桥接发起请求。
- 为遵守「不删断言」，`.studypack` manifest 的 `version` 字段保持 `"2.0.0"`（作为 studypack-open-v1 数据契约版本），App 版本为 2.1.0。
- Key 的 v2.0.0 兼容读取层会返回明文，但落盘一律为 AES-GCM 密文；该兼容层仅为冻结断言保留，不进入导出链路。
