## 一、请先读的基准

框架文档 v1.0，重点看：§0 产品定位、§1.6 自查项、§2 框架总览、§3 领域模型、§4.2 全局时间视图、§4.3 时段池、§4.4 薄弱点速查卡、§4.6 会话状态机、§4.7 笔记三通道、§4.9 策略开关层、§5 平台约束。

**一句话产品**：安卓为主的个人学习助手，两个角色——「秘书」（提醒任务、日程、倒计时）+「教练」（发现薄弱点后用 AI 陪跑 学习→测验→费曼复述→个性化笔记→复习 的完整闭环）。用户是**深圳中学高中生，新高考 I 卷 / 人教 A 版**，一切资料要贴高考。

## 二、设计必须承接的 8 条硬约束

| # | 约束 | 对页面/视觉的含义 |
|---|---|---|
| 1 | **信息克制**（用户一贯偏好） | 桌面小组件**只显示最近一个任务 + 倒计时**；考前卡一行一个坑；AI 笔记与手写笔记**不合订**（用户明确说「合订太冗长」）。不要堆功能、不要长文档式界面 |
| 2 | **绿色 = 可学习空闲时段的专用色** | 「绿色空闲时段」是产品的核心视觉语言，请让它成为日历/排期里的**专色**，不要挪作「成功/完成」等其它语义，避免歧义 |
| 3 | **三层视图层级** | `桌面 Widget（最小态）→ 今日视图 → 全局日历`；日历是**全局**的，任务 / 规划学习 / 校历三层叠加且已标注干什么 |
| 4 | **教学区域禁用电子设备** | 必须有**打印 / 导出纸质**入口；打印态**黑白输出仍可读**，不能只靠颜色区分（例如薄弱程度要同时有文字/形状标记） |
| 5 | **进考场前可用手机** | 考前速查卡需要**屏幕态**（Widget 考前速览 / 考前最后一眼）与**打印态**同源双渲染，内容一致 |
| 6 | **设备矩阵** | vivo S7 手机（6.4" 竖屏，主用）/ 联想 13" 安卓平板（横屏分屏主战场）/ iQOO、红米（不同安卓系统）/ iPhone 只走查看器。四家安卓系统行为不一致，**不要写死分屏布局**，需「支持则并排、不支持则跳转」的降级形态 |
| 7 | **流程状态要可见** | 会话状态机：资源就绪 →〔摸底测验，可跳过〕→ 视频+笔记 → 测验 →〔达标〕总结费曼 → AI 笔记 → 复习计划；未达标走「归因 → 费曼 → 再测」。复习固定为「复述→纠正→练手题→今日新内容」 |
| 8 | **一切「可选但存在」** | 提醒方式（振动/声音/无）、开始时机（立即/将来）、摸底测验显隐、**内置笔记区显示/不显示**、提前量（2/5/自定义）、`SessionIntent`（跟随/挑战/刷自信）——都是策略开关，界面要能表达「有这个功能，但用不用由我定」，而不是把流程写死 |

**补充**：离线可用（无网/无 key 时 AI 节点标「待处理」，但看视频、记笔记、做已有题目不能卡住）；`api_key` 不进导出包；导出格式 `.studypack` 纯开放不加密。

## 三、页面清单草稿（起跑线，不是定稿）

| # | 页面 / 组件 | 关键内容 | 备注 |
|---|---|---|---|
| 1 | **桌面小组件** | 最近一个任务 + 倒计时；点击跳转 | 最小态，信息克制的最高优先级 |
| 2 | **今日视图（首页）** | 最近任务（可一键跳转外部 App）、今日日程、距下一任务倒计时 | 承接原始情境 A / B |
| 3 | **全局日历** | 月/周视图，任务 + 规划学习 + 校历三层叠加；**绿色空闲时段**可点选 | 规划排期入口 |
| 4 | **任务详情 / 编辑** | 习惯性 vs 一次性、周期、提醒方式与提前量、跳转动作 | |
| 5 | **规划创建向导** | 目标 + 量化指标(75%) + 时限(15天) + 挑绿色时段 + 立即/将来 + 提前量 | 分步，别一屏塞满 |
| 6 | **学习会话页** | 视频资源 / 题目 / 内置笔记区（可显隐）/ 测验 / 费曼对话 / 进度状态 | 核心页，状态机驱动 |
| 7 | **复习闭环页** | 复述 → AI 纠正 → 练手题 → 进入今日内容 | 固定流程，不可配 |
| 8 | **薄弱点速查卡** | 每条一行：知识点 + 一行提醒 + 薄弱程度；屏幕态 / 打印态切换 + 导出 | 考前用 |
| 9 | **笔记** | AI 笔记 / 我的笔记**两份独立**；段落角标「笔迹 2」双向跳转；A/C/D 三通道入口（Notein 分屏、PDF 归档、内置区） | 不合订 |
| 10 | **设置与策略开关** | L0 全部开关、数据外发白名单、AI Provider 配置 | |
| 11 | **数据导入导出** | `.studypack` 导出 / 导入、校验、敏感内容说明 | |

## 四、画风的初步意见（仅供参考）

1. **冷静、低干扰、高可读性**：面向高中生的高频学习工具，建议减少花哨动效与装饰，把注意力留给「下一个任务 / 绿色时段 / 一行提醒」。
2. **「纸质考试感」作为可选方向**：用户要打印态、要贴高考、要在教学区域用纸质卡；界面若能呼应「讲义/答题卡」的克制排版会自洽，但**是否采用由千问定**。
3. **绿色的语义独占**（见约束 2），并在**黑白打印下不给绿色单独承担信息**。
4. **密度分层**：Widget 极简 → 今日视图中等 → 日历/规划可承载较多信息；不要让每一屏都满。
5. **安卓多系统一致性**：不要依赖某一家的系统组件外观；分屏与跳转两种形态都要有像样的布局。
6. **手写笔迹区**要能容纳压感笔迹（perfect-freehand 风格），但**可隐藏**——隐藏时该区域不占位。
