## 一、App 是什么（自包含速览 · 千问只看本文件即可开工）

> 本节刻意把框架文档的关键结论**全文搬进来**，避免「见 §x」造成信息缺口。完整论证另见 `docs/学习助手App_软件框架.md` v1.0（同样附 PDF），但**不读它也能做设计**。

### 1.1 定位与用户

| 项 | 内容 |
|---|---|
| 产品 | 安卓为主的**个人学习助手**，两个角色：**秘书**（提醒日常任务、呈现日程、倒计时）+ **教练**（发现薄弱点后用 AI 陪跑「学 → 会 → 记住」的完整闭环） |
| 用户 | **深圳中学高中生**；广东 **新高考 I 卷**（3+1+2，数学不分文理）、**人教 A 版 2019** 教材；资料与题目必须贴高考 |
| 主用设备 | vivo S7 手机（6.4" 竖屏）、联想 13" 安卓平板（横屏分屏）；家人 iQOO / 红米 / iPhone，四家安卓系统行为不一致 |
| 环境硬约束 | **教学区域禁用电子设备**；**课间用不了手机**；**进考场前可以用手机** |
| 首个真实场景 | 上完数学课发现「基本不等式」薄弱 → 建 15 天规划，目标「能解决 75% 相关题目、遇到同类题脑中有思路」 |

不是「待办清单 + 网课浏览器」的拼装，而是**以规划为主干、会话为执行单元、费曼复述为理解检验核心**的闭环系统。

### 1.2 两个闭环

- **闭环① 任务/习惯维系**：习惯性任务（如早晨「打开不背单词」）→ 到时提醒（振动/声音/无）→ 一键跳转外部 App 执行 → 记录 → 下一周期。
- **闭环② 能力精进**：发现薄弱 → 建规划 → 会话学习（费曼式总结）→ 复习闭环 → 直到达成量化目标。

两者共用同一套 AI 能力层、笔记/资源接入层、全局时间视图与本地数据底座。

### 1.3 三层全局时间视图（页面骨架）

| 层级 | 内容 |
|---|---|
| **桌面 Widget（最小态）** | 常驻桌面，**只显示最近一个任务 + 距下一任务倒计时**；点一下跳转 |
| **今日视图** | 今天的既定日程表 |
| **全局日历** | 全局、已描述「干什么任务」；**任务 / 规划学习 / 校历三层叠加**；**绿色 = 可学习空闲时段** |

日历里被判定为「可学习」的子集叫 `SlotPool`。它**不是一条规则，而是四个来源的池子**：① 按课程表手动标绿（在校）② 学校小程序课表（不爬，走跳转/文件桥接）③ 常驻作息模板（07:00–07:30 / 13:00–13:30 / 17:20–18:20 / 21:30–21:50，每天从中勾选、可取消）④ 临时自定义（校运会等，部分由校历活动自动供给）。

**绿色的判定** = `空闲 ∧ 设备可用 ∧ 能用手机 ∧ 时长够`。四个常驻时段合计 **140 分钟/天**，其中 20/30 分钟是碎片——碎片放复习闭环，整块 60 分钟（17:20–18:20）才排新内容，会话要能**拆分、跨时段续接**。

### 1.4 学习会话状态机（核心页要能表达这些状态）

```
AI 准备资源 →〔摸底测验：可选，可跳过〕→ 视频学习 + 笔记 → 相关测验
   → 达标? ─ 是 → 总结（我复述 → AI 纠正 → 反复 → 确认理解）
                 → 生成个性化 AI 笔记 → 生成复习计划纳入规划
           └ 否 → AI 错因归因 → 回到费曼复述-纠正 → 再测一遍（循环）
```

- **75% 是双层**：单次测验正确率 ≥75% = 会话通过线；15 天到期整体解决率 ≥75% = 规划目标线。
- **复习闭环固定、不可配**：下次学习前 `复述上次理解 → AI 纠正 → 反复确认 → 几道简单练手题 → 进入今天的新内容`。
- **未达标不重学、不直接换题**：走「归因 → 继续费曼 → 再测」，归因产出 **薄弱点条目**（精确到知识点叶子节点，带三维标签、薄弱程度、证据、一行考前提醒）。

### 1.5 「可选但存在」的行为（界面要能表达，不要写死流程）

统一归到 **L0 策略与开关层**：提醒方式（振动/声音/无）、提醒提前量（全局默认 + 预设 2/5 分钟 + 自定义，建规划时设）、开始时机（立即/将来）、摸底测验显隐、**内置笔记区显示/不显示**、数据外发白名单、`SessionIntent`（跟随系统 / 挑战 / 刷自信，仅当次生效）。**唯一不可配的是复习模式**（固定模式 2）。

### 1.6 笔记：三通道 + 两份独立 + 快速对应

| 通道 | 形态 | 数据归属 |
|---|---|---|
| A 系统分屏 / 跳转 | 已买断的 Notein，同屏两块区域或一键跳回 | 原始笔迹入不了库，只登记外部引用 + 快照 |
| C PDF 桥接 | 导出讲义 PDF → Notein 批注 → 归档回来 | 以文件形式可带走 |
| D 内置笔记区 | App 内一块区域，**可显示 / 不显示**（MIT 零件自研） | 完全归我们 |

**AI 笔记与「我的笔记」分开存、双向关联**（用户明确否决「合订」，理由是太冗长）。快速对应靠 `anchorId`（知识点节点 ID + 会话 ID + 薄弱点 ID）做**本地索引**，不需要把笔记交给 AI；交互上是 AI 笔记段落旁一个「笔迹 2」角标，点开拉出对应笔迹，反向也能跳回。复习时默认**只显示 AI 笔记 + 考前速查卡**，我的笔迹按需展开。

### 1.7 资源与高考对齐（决定内容呈现的可信度）

资料优先级：`自己的资料 > 权威题库（学科网）> B站视频（仅跳转）> AI 生成（受限）`。每份资源强制带 `来源 / 教材版本·考纲标签 / 年份地区 / 题型·分值·难度`。**AI 只做检索匹配 + 讲解 + 基于真实母题的变式，禁止无来源的题冒充高考题**；变式按四档递进（换数字 → 换情境 → 换设问 → 开放探究），题库需备到压轴档。

### 1.8 数据与技术底座

- **本地存储**，主动（自动快照）+ 手动保存；`.studypack` 全开放格式（JSON + SVG + PDF + Markdown）**纯开放不加密**，可全量导入导出、跨设备；`api_key` **不进包**（存 Android Keystore）。
- **AI 层可插拔**：能力接口固定（分析薄弱点/检索资源/出题/判卷/错因归因/复述纠正/生成笔记/生成复习计划/截图识别），Provider 适配器可换（默认 DeepSeek `deepseek-flash`）。**无网/无 key 时 AI 节点标「待处理」，但不阻塞看视频、记笔记、做已有题目**。
- **Flutter**；A 通道做「能力探测 + 自动降级」（支持分屏则并排，否则跳转）；iPhone 只走导出包 + 轻量查看器（**数据可移植 ≠ 应用跨平台**）。

### 1.9 设计者要抓住的一贯偏好

用户反复表现出 **信息克制**：Widget 只显示一个任务、考前卡一行一个坑、AI 笔记与手写笔记不合订、桌面组件要「小一点」。**不要把每一屏都填满**。

## 二、设计必须承接的 8 条硬约束

| # | 约束 | 对页面/视觉的含义 |
|---|---|---|
| 1 | **信息克制**（用户一贯偏好） | 桌面小组件**只显示最近一个任务 + 倒计时**；考前卡一行一个坑；AI 笔记与手写笔记**不合订**（用户明确说「合订太冗长」）。不要堆功能、不要长文档式界面 |
| 2 | **绿色 = 可学习空闲时段的专用色** | 「绿色空闲时段」是产品的核心视觉语言，请让它成为日历/排期里的**专色**，不要挪作「成功/完成」等其它语义，避免歧义 |
| 3 | **三层视图层级** | `桌面 Widget（最小态）→ 今日视图 → 全局日历`；日历是**全局**的，任务 / 规划学习 / 校历三层叠加且已标注干什么 |
| 4 | **教学区域禁用电子设备** | 必须有**打印 / 导出纸质**入口；打印态**黑白输出仍可读**，不能只靠颜色区分（例如薄弱程度要同时有文字/形状标记） |
| 5 | **进考场前可用手机** | 考前速查卡需要**屏幕态**（Widget 考前速览 / 考前最后一眼）与**打印态**同源双渲染，内容一致 |
| 6 | **设备矩阵** | vivo S7 手机（6.4" 竖屏，主用）/ 联想 13" 安卓平板（横屏分屏主战场）/ iQOO、红米（不同安卓系统）/ iPhone 只走查看器。四家安卓系统行为不一致，**不要写死分屏布局**，需「支持则并排、不支持则跳转」的降级形态 |
| 7 | **流程状态要可见** | 会话状态机：资源就绪 →〔摸底测验，可跳过〕→ 视频+笔记 → 测验 →〔达标〕总结费曼 → AI 笔记 → 复习计划；未达标走「归因 → 费曼 → 再测」。复习固定为「复述→纠正→练手题→今日新内容」 |
| 8 | **一切「可选但存在」** | 提醒方式（振动/声音/无）、开始时机（立即/将来）、摸底测验显隐、**内置笔记区显示/不显示**、提前量（2/5/自定义）、`SessionIntent`（跟随/挑战/刷自信）——都是策略开关，界面要能表达「有这个功能，但用不用由我定」，而不是把流程写死 |

**补充**：离线可用（无网/无 key 时 AI 节点标「待处理」，但看视频、记笔记、做已有题目不能卡住）；`api_key` 不进导出包；导出格式 `.studypack` 纯开放不加密。

## 四、画风的初步意见（仅供参考）

1. **冷静、低干扰、高可读性**：面向高中生的高频学习工具，建议减少花哨动效与装饰，把注意力留给「下一个任务 / 绿色时段 / 一行提醒」。
2. **「纸质考试感」作为可选方向**：用户要打印态、要贴高考、要在教学区域用纸质卡；界面若能呼应「讲义/答题卡」的克制排版会自洽，但**是否采用由千问定**。
3. **绿色的语义独占**（见约束 2），并在**黑白打印下不给绿色单独承担信息**。
4. **密度分层**：Widget 极简 → 今日视图中等 → 日历/规划可承载较多信息；不要让每一屏都满。
5. **安卓多系统一致性**：不要依赖某一家的系统组件外观；分屏与跳转两种形态都要有像样的布局。
6. **手写笔迹区**要能容纳压感笔迹（perfect-freehand 风格），但**可隐藏**——隐藏时该区域不占位。
