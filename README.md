# study-agent

一款**辅助学习 App** 的项目仓库：提醒日常任务、呈现日程，并在发现知识薄弱点后用 AI 陪跑「学习 → 测验 → 费曼复述 → 个性化笔记 → 复习」的完整闭环。以 Android 为主，数据本地存储、可全量导入导出。

当前阶段：**需求澄清已收敛，尚未开始编码**。

## Git 约定

- **每次修改都要上传**：任何文件改动后即 `git add` → `git commit` → `git push origin main`，不积压、不囤积本地提交。
- **凭证不入库**：API key / token 只存本地（Android Keystore 或本地 600 权限文件），既不写进代码，也不写进 `.studypack` 导出包。`.gitignore` 已做兜底。
- 提交信息用简短中文，说明改了什么。

## 关键约束速览

- 数据本地存储，全开放格式的 `.studypack` 保证「所有数据能带走」。
- AI 层可插拔（能力接口固定 + Provider 适配器可换），默认 DeepSeek。
- 资料必须贴切高考：来源可追溯、带考纲标签，AI 不凭空造题。
- 内置笔记区可显示/不显示；已购 Notein 走分屏 / PDF 桥接，不做内嵌。
